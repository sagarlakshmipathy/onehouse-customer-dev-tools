# Onehouse customer dev tools

Tools that help you prepare and check your environment for Onehouse.

| Tool | What it does |
|------|--------------|
| [cdc-prereq-check](cdc-prereq-check/) | Checks that a Postgres, MySQL or Oracle database is ready to be a Onehouse CDC source. It checks the network, the cloud setup and the database, and prints the fix for each failure. |

Each tool has its own README with the install and run steps.
